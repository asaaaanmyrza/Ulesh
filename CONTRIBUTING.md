# Contributing to Ulesh

Thank you for your interest in Ulesh, an open-source project that connects
restaurants and charity organizations in Kazakhstan to reduce food waste.

## Ways to contribute
- Suggest ideas or report problems by opening an Issue.
- Improve documentation.
- Review Pull Requests from other contributors.

## How to propose an idea
1. Open the **Issues** tab and click **New issue**.
2. Give it a clear title and describe the idea or problem.
3. Wait for feedback from the team before starting large changes.

## Workflow
1. **Issue**: create or pick an Issue and assign yourself.
2. **Branch**: create a branch from `main` (for example, `docs/readme`).
   Do not commit directly to `main`.
3. **Commit**: make your changes and commit them to your branch with a
   clear message.
4. **Pull Request**: open a PR with base `main` and compare set to your
   branch. Describe what you did and link the Issue (for example,
   `Closes #1`).
5. **Review**: another team member reviews the PR. Fix any comments.
6. **Merge**: after approval, the PR is merged into `main`.
